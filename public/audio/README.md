# Sons de motivation (MP3)

Dépose ici tes fichiers MP3, nommés exactement :

- `motivation-1.mp3`
- `motivation-2.mp3`
- `motivation-3.mp3`
- `motivation-4.mp3`

Ils apparaissent automatiquement dans l'onglet **Motivation** de l'app.
Tu peux changer les titres et les noms de fichiers dans `src/lib/motivation/tracks.js`.

## ⚠️ Droits d'auteur

Les extraits du film « Le Loup de Wall Street » sont **protégés**. N'héberge pas
d'extraits piratés sur une URL publique (Vercel). Utilise :

- tes **propres enregistrements** (ta voix, tes affirmations), ou
- des extraits dont tu détiens les **droits**, en **usage strictement personnel**.
