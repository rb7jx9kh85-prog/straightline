# Images (onglet Motivation)

Dépose ici :

- `belfort.jpg`  → portrait de Jordan Belfort
- `dicaprio.jpg` → photo de Leonardo DiCaprio

(JPG, PNG ou WebP — si tu utilises un autre format, adapte les chemins dans
`src/components/Motivation.jsx`.)

Tant que les fichiers ne sont pas là, l'app affiche un **cadre stylisé** à la place.

## ⚠️ Droits d'auteur / droit à l'image

Les photos de personnes réelles et les visuels du film sont protégés. Utilise des
images dont tu détiens les droits (ou en usage personnel). Évite de publier des
photos protégées sur une URL publique.
